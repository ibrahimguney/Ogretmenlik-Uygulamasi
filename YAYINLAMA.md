# GitHub Pages Yayınlama

Canlı portalı açmak için GitHub deposunda şu ayarlar yapılır:

1. Settings bölümünü açın.
2. Pages sayfasına girin.
3. Build and deployment bölümünde Source olarak Deploy from a branch seçin.
4. Branch olarak main ve klasör olarak /(root) seçin.
5. Save düğmesine basın.

Yayın adresi genellikle:

https://ibrahimguney.github.io/Ogretmenlik-Uygulamasi/

İlk yayın birkaç dakika sürebilir. Ana sayfa index.html, stiller styles.css ve haftalık kartlar app.js üzerinden yüklenir.
