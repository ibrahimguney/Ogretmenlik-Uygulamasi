## GitHub’a yükleme kuralı

Bu formların doldurulmuş hâli, öğrenci gözlem notları, öğrenci ürünleri ve portfolyo kanıtları bu GitHub deposuna yüklenmez. Formlar yalnızca öğrencinin cihazında tutulur; PDF çıktısı kurumun belirlediği güvenli kanaldan teslim edilir.

Formu doldurduktan sonra yazdır seçeneğiyle PDF olarak kaydedebilir veya çıktıyı portfolyonuza ekleyebilirsiniz. Öğrenci adlarını kodlayın ve kişisel veri kullanmayın.

## Haftalık staj raporunu PDF olarak kaydetme

1. [Haftalık staj raporunu açın](./haftalik-staj-raporu.html).
2. Öğrenci bilgilerini ve haftalık etkinlik/gözlem raporunu doldurun.
3. **PDF olarak kaydet** düğmesine basın.
4. Açılan yazdırma penceresinde **Hedef / Yazıcı → PDF olarak kaydet → Kaydet** seçin. A4 dikey düzen kullanın; tarayıcı üstbilgi/altbilgisini kapatın.
5. PDF dosyasını kendi bilgisayarınıza kaydedin. İmza ve onay alanlarını çıktıda tamamlayın.

Taslak saklama isteğe bağlıdır ve yalnızca kullanılan tarayıcıya kaydedilir. Ortak bilgisayarda **Formu ve taslağı temizle** düğmesini kullanın. Uzun raporlar sonraki sayfalara devam eder. GitHub hesabı gerekmez; doldurulan bilgiler sunucuya gönderilmez.
